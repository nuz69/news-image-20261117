## How it works

`main.py` is written in Python 3.13 using standard library modules only (`os`, `pathlib`, `shutil`). It locates `entry.png` relative to the script directory and copies it to `$MAKEFUN_OUTPUT_DIR/entry.png` (defaulting to `/output/entry.png`). 
- **Deterministic:** Two runs produce identical bytes.
- **Offline:** No network requests are made during execution.
